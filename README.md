Mobile E-Commerce Application

This project is a mobile e-commerce app built with React Native and TypeScript, designed to provide a fast, user-friendly shopping experience. It allows users to browse products, add items to the cart, and manage orders seamlessly on mobile devices.

🚀 Technologies & Packages Used

React Native (0.81.0) – Core framework for building mobile apps

React (19.1.0) – UI development

Axios (1.11.0) – API requests and server communication

React Redux (9.2.0) – State management across the app

react-native-toast-message (2.3.3) – User notifications and alerts

react-native-safe-area-context (5.5.2) – Handling device safe areas

react-native-screens (4.15.1) – Optimized screen management and navigation

react-native-svg (15.12.1) – Dynamic SVG rendering

iconsax-react-nativejs (0.0.8) – Vector icons for UI
